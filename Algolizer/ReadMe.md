# About Algolizer
Algolizer is a web-based algorithm visualization tool built using **JavaScript, HTML5, and CSS3.**
It helps students, developers, and educators understand algorithms through interactive, step-by-step visual demonstrations.

---

# How to Use
## Algolizer
- Open the ```firstPage.html``` file.

<img src="https://github.com/yash-ingle/Projects/blob/main/Algolizer/screenshots/Algolizer_1.png">

- Click on ```Get Started``` button.
- Select anyone algorithm form the list of algorithm. (Example: **Linear Search**)

<img src="https://github.com/yash-ingle/Projects/blob/main/Algolizer/screenshots/Algolizer_2.png">

- Click on ```Start``` button to execute the algorithm.

<img src="https://github.com/yash-ingle/Projects/blob/main/Algolizer/screenshots/Algolizer_3.png">
  
> As shown in the visualization, the **Linear Search** algorithm checks each element one by one. Elements that do not match the target are highlighted in **purple**, while the element that matches the target is highlighted in **green**, making it easy to track the search process visually.

- You can also customize your **Input Set**, just fill in the fields and click on ```Submit``` button.

<img src="https://github.com/yash-ingle/Projects/blob/main/Algolizer/screenshots/Algolizer_4.png">

- Now click on ```Start``` button, to see the visualization of the algorithm execution on your custom **Input Set**.

<img src="https://github.com/yash-ingle/Projects/blob/main/Algolizer/screenshots/Algolizer_5.png">

> **Note:** You can stop the algorithm execution at any time by clicking the `Stop` button.

## List of Algorithms Supported by Algolizer

* Linear Search.
* Binary Search.
* Dutch National Flag Algorithm.
* Cocktail Shaker Sort.
* Sieve of Eratosthenes.
